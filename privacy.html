Privacy Policy

1. Data Collection

TikTok Auto Publisher is a desktop application that runs locally on your machine. We do not collect, store, or transmit any personal data to external servers.

2. Local Data Storage

The following data is stored exclusively on your local device:

  • TikTok OAuth tokens (access token, refresh token) — stored in a local JSON file
  • TikTok API credentials (client key, client secret) — stored in local text files
  • Video files pending upload — stored in your designated working directories

None of this data is sent to any third-party server. The Application operates entirely on your machine.

3. Third-Party Services

The Application communicates directly with TikTok's official API (open.tiktokapis.com) for authentication and video publishing. Your data is subject to TikTok's Privacy Policy during these interactions.

4. No Analytics / No Tracking

The Application does not include any analytics SDKs, tracking pixels, or telemetry. We do not collect usage statistics, crash reports, or any behavioral data.

5. Security

OAuth tokens and credentials are stored in plain text files on your local filesystem. You are responsible for securing your machine and not sharing these files.

6. Contact

For privacy-related questions, contact the developer through: github.com/testpochtano-spec/tiktok-auth
